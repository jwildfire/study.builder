A clinical trial's data, simulated in your browser

study.builder makes a whole synthetic study, from raw data to ADaM tables, site metrics and reports, and lets you look through all of it. R runs in the page, so nothing is installed and no study data is sent anywhere (R itself is downloaded the first time). Every row is made up: no real participant or site is in it.

  1. Portfolio The list of studies you can have. Open a ready-made study at once, or build one from its settings.
    Try the portfolio →
  2. Study view One study, looked through in five sections: Overview; Design, the protocol and its schedule; Data, the pipeline and every table; Operations, the site metrics, safety and one participant; Reporting, the results by arm. Pick a monthly snapshot to see the study as it stood then.
    Try the study view →
  3. Study builder Describe your own study: its size, a CDISC protocol to follow, the layers and domains to make. The first build takes about a minute.
    Try the study builder →

New here? Start with the study view: it opens on the CDISC pilot protocol study. To use a study in your own page or package, see Use it from another page and the README.

Use it from another page

One script defines StudyBuilder. mount draws all three parts together in an element and hands you the study the reader chose; mountStudy draws the study view alone; buildStudy builds a study with no page at all. 

<script src="https://jwildfire.github.io/study.builder/study.builder.js"></script>
<div id="builder"></div>
<script>
  // The builder on your page. `study.files()` is { raw, standard }: each a list of { name, text }.
  StudyBuilder.mount('#builder', {
    onStudy(study) {
      const { raw, standard } = study.files();
      myApp.loadRaw(raw);
      myApp.loadFiles(standard);
    }
  });

  // Or no page at all: settings in, data out.
  const study = await StudyBuilder.buildStudy({
    participants: 200,
    sites: 15,
    months: 6,
    domains: ['AE', 'LB', 'VS']
  });
  study.domains.find((domain) => domain.id === 'AE').text; // the CSV text
</script>
Everything runs in this browser, and no study data is sent anywhere; building a study downloads R and its packages from webr.r-wasm.org and repo.r-wasm.org. Data is simulated by a modified copy of gsm.datasim 2.1.0: the additions are not Gilead's.
